# Changelog

All notable changes to the MyFans monorepo (`contract/`, `backend/`, `frontend/`) are documented here.

Entries are generated from [Conventional Commits](https://www.conventionalcommits.org/) by `npm run changelog` and reviewed in the release PR. See the [Changelog Guide](docs/CHANGELOG_GUIDE.md). Soroban contract version history is also kept in [contract/CHANGELOG.md](contract/CHANGELOG.md), which is the source of truth for contract crate versions and upgrade notes.

History before the first `v*` tag is mixed: many squash commits predate the Conventional Commit rule. It is not backfilled here. Use `git log` or the GitHub PR list for that period.
